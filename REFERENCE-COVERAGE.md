# LSE reference coverage

This crate targets the historical LSE described by Hebenstreit and Noyelle (1973), with additions visible in Berche's 1981 comparison and the EPI/CNDP 1982 *Aide mémoire*. It does not target LSE-2000/Phoenix as a whole.

| Reference area | Implemented behavior | Remaining gap |
| --- | --- | --- |
| Program lines, identifiers, and declarations (1981 comparison, pp. 33–34; 1982 aide-mémoire, pp. 1–2) | Numbered lines from 1 to 32767; identifiers begin with a letter and contain at most four following letters or digits; semicolon-separated statements; `CHAINE`, `BOOLEEN`, `FORME`, and `PAGE` declarations take effect when their line executes; `MOTIF code = form` registers an opaque form with the graphics host | Statements without a line number are rejected. |
| Numeric values and expressions (1973 article; 1982 aide-mémoire, pp. 2, 4) | Real values, assignment with `←`, ASCII `<-`, or `_` (as used for the assignment glyph in surviving program transcriptions), arithmetic, right-associative `↑`, comparisons, Boolean expressions, `RAC`, `ABS`, `ENT`, `SIN`, `COS`, `TAN`, `EXP`, `LGN`, `ATG`, `ALE(1)`, and the indexed system functions `TEM`, `TZL`, `NIV`, `TYP`, and `IND` routed through `Host::system_function` | `=` is also accepted as an assignment compatibility form. `TEM`/`TZL`/`NIV`/`TYP`/`IND` semantics are assigned to the host because the selected index gives only signatures, not definitions. The `DIJ` operator appears in the 1982 index, but its truth table is unavailable. |
| Text (1973 article; 1981 comparison; 1982 aide-mémoire, pp. 3–4; LSE 2000 reference) | Declared `CHAINE` variables, apostrophe literals, `!`, `SCH`, `GRL`, `CCA`, `EQC`, `DAT`, `LGR`, `POS`, `CNB`, `EQN`, `PTR`, `SKP`, `ICH`, `MCH`, `REP`, `RCC`, `TMA`, and `TMI`. `RCC` compares lexicographically and accepts an optional 256-character collation order. | The exact historical character encoding and sorting order are not common across the selected editions; the optional order must contain 256 unique Unicode scalar values, and text containing values absent from that order is rejected. |
| Booleans (1981 comparison; 1982 aide-mémoire, p. 4) | `BOOLEEN`, `.VRAI.`, `.FAUX.`, `ET`, `OU`, and `NON` | Exact edition differences beyond the cited sources are not modeled. |
| Control (1973 article; 1982 aide-mémoire, pp. 2–3; 1985 LSE83 comparison) | `ALLER EN`, `SI` / `ALORS` / `SINON`, nested `DEBUT` / `FIN` compound statements, labeled `FAIRE` loops with optional `PAS` and either `JUSQUA` or `TANT QUE`, and `PAUSE`. Loop step and limit expressions are reevaluated at each loop header. | Compound blocks are limited to one numbered source line; the accessible index does not fully establish multiline block rules. |
| Input, output, memory, and files (1973 article; 1981 comparison, pp. 36–38; 1982 aide-mémoire, pp. 2–3) | Host-backed `LIRE` for scalar variables or every element of an allocated table; static `LIRE` prompts; `AFFICHER` with `/`, `X`, `C`, `L`, literals, repetition factors, and `F`/`E`/`U` numeric formatting; `LIBERER`; keyed `GARER`/`CHARGER` for scalar or table records; file- or record-level `SUPPRIMER` | The 1973 article and 1982 aide-mémoire show different `GARER`/`CHARGER` argument orders; this crate follows the 1982 signatures. The source requires all table values to be read but does not specify their sequence; this implementation reads in row-major order. The 1981 comparison defines dynamic factors for `AFFICHER` but does not specify their value source in `LIRE`'s format-only form, so `LIRE` prompts use fixed factors. Status numbers depend on the selected host; the CLI uses `0` for success and `1` for a missing record/file. |
| Arrays (1981 comparison, pp. 28–29; 1982 aide-mémoire, pp. 1–2) | Dynamically allocated numeric, string, Boolean, and opaque form tables with one through seven dimensions; dimensions are evaluated at the declaration line; 1-based indexing; row-major element access; indexed assignment; `LIRE` supports numeric, string, and Boolean elements | Graphics form elements are uninitialized until assigned; `LIRE` does not define a serialization format for them. Allocation is bounded to one million elements. |
| Procedures and recursion (1981 comparison, pp. 35–36) | In-source or host-loaded `PROCEDURE &name(...)` definitions, numeric-label bodies, `LOCAL` formals passed by value, other formals passed by reference, local scalar/table scope, procedure-function references, `RESULTAT`, `RETOUR`, and recursive calls | A procedure without `RETOUR` is read through the next procedure header or end of source. Recursion is bounded at 128 nested calls. The CLI resolves external definitions as `<name>.lse`; the original library search order is not described in the selected references. |
| Graphics, external programs, and monitor (1973 article; 1982 aide-mémoire, pp. 1–4) | `FORME`, `PAGE`, `MOTIF`, `TABLEAU FORME`, `:` juxtaposition, `%` superposition; `VEC`, `VEQ`, `VEX`, `VEY`, `MTF`, `REF`, `ROT`, `TRN`, `SMX`, `SMY`, `SMO`, `AFX`, `AFY`, `MAT`, `HOM`; and `TRACE`, `INSERER`, `CADRER`, `TRANSFERER`, `MARGER`, `ALLUMER`, `ETEINDRE`, `NETTOYER`, `CIBLE` are parsed and delegated through typed host methods. Opaque graphic handles retain whether they are forms or pages. `EXECUTER program, argument [, status]` routes through `Host::execute_program`. | The indexed aide-mémoire lists signatures but not renderer or transformation mathematics; those are host responsibilities. Interactive monitor commands belong to the original environment, not program source. |

The `Host` supplies input, output, pause, date/time, random values, keyed file storage, external program execution, and the graphics object/operator/function/command services. `REP` rejects results larger than 16 MiB to bound allocation. These implementation limits are not claims about the original runtime.

## Sources

- [Hebenstreit and Noyelle, “Un langage symbolique destiné à l’enseignement : LSE” (1973)](https://www.epi.asso.fr/revue/06/b06p010.htm), especially §§1–3.
- [Berche, “Comparaison LSE/BASIC” (1981)](https://ife.ens-lyon.fr/publications/edition-electronique/revue-francaise-de-pedagogie/INRP_RF056_2.pdf).
- [EPI/CNDP, “Aide mémoire pour LSE / L.S.E. pour tous” (1982)](https://www.epi.asso.fr/blocnote/plaquetteLSE.pdf), especially the syntax and function indexes.
- [Arsac, “LSE 83” (1985)](https://www.epi.asso.fr/revue/38/b38p116.htm), which explicitly compares its loop evaluation rules with the original LSE behavior.
